# คู่มือความรู้ Local AI: AI, Machine Learning, Python และ Automation

เอกสารภาษาไทยสำหรับใช้เรียนรู้และนำเข้าในระบบ Local AI แบบ RAG

## 1. Artificial Intelligence (AI) คืออะไร

Artificial Intelligence หรือ AI
คือแนวคิดและเทคนิคที่ทำให้คอมพิวเตอร์ทำงานบางอย่างซึ่งปกติต้องอาศัยความสามารถของมนุษย์
เช่น การเข้าใจภาษา การจำแนกรูปภาพ การวางแผน การค้นหาคำตอบ และการช่วยตัดสินใจ

AI ไม่ได้หมายความว่าระบบคิดหรือเข้าใจเหมือนมนุษย์เสมอไป ระบบทำงานตามแบบจำลอง ข้อมูล
กฎ และวิธีคำนวณที่ถูกออกแบบหรือเรียนรู้ไว้

ตัวอย่างการใช้ AI: - ระบบแนะนำภาพยนตร์หรือเพลง -
ระบบตรวจจับความผิดปกติของเครื่องจักร - ผู้ช่วยตอบคำถาม - ระบบรู้จำเสียงและภาพ -
การคาดการณ์แนวโน้มจากข้อมูล

## 2. Machine Learning (ML)

Machine Learning คือสาขาหนึ่งของ AI ที่ทำให้ระบบเรียนรู้รูปแบบจากข้อมูล
เพื่อนำไปทำนายหรือจัดประเภทข้อมูลใหม่ แทนการเขียนกฎทุกกรณีด้วยมือ

ประเภทหลัก: 1. Supervised Learning: เรียนจากข้อมูลที่มีคำตอบกำกับ เช่น
ข้อมูลอุณหภูมิมอเตอร์พร้อมป้ายกำกับว่าปกติหรือผิดปกติ 2. Unsupervised Learning:
ค้นหารูปแบบหรือกลุ่มจากข้อมูลที่ไม่มีคำตอบกำกับ เช่น การจัดกลุ่มเอกสารตามความคล้ายกัน 3.
Reinforcement Learning:
เรียนรู้จากผลตอบแทนหรือบทลงโทษที่ได้รับจากการกระทำในสภาพแวดล้อม

คำศัพท์สำคัญ: - Dataset: ชุดข้อมูลที่ใช้พัฒนาและทดสอบระบบ - Feature:
ตัวแปรหรือคุณลักษณะที่ใช้เป็นข้อมูลนำเข้า - Label:
คำตอบหรือประเภทที่ต้องการให้โมเดลทำนาย - Training:
ขั้นตอนเรียนรู้พารามิเตอร์จากข้อมูล - Inference: การนำโมเดลที่ฝึกแล้วไปทำนายข้อมูลใหม่ -
Overfitting: โมเดลจำรายละเอียดของข้อมูลฝึกมากเกินไป จนทำงานกับข้อมูลใหม่ได้ไม่ดี -
Evaluation: การประเมินประสิทธิภาพด้วยข้อมูลและตัวชี้วัดที่เหมาะสม

## 3. Deep Learning และ Neural Networks

Deep Learning เป็นส่วนหนึ่งของ Machine Learning ที่ใช้โครงข่ายประสาทเทียมหลายชั้น
(Neural Networks) เพื่อเรียนรู้รูปแบบที่ซับซ้อนจากข้อมูล เช่น รูปภาพ เสียง ข้อความ
และสัญญาณจากเซนเซอร์

องค์ประกอบทั่วไป: - Input layer: รับข้อมูล - Hidden layers:
ประมวลผลและเรียนรู้ตัวแทนของข้อมูล - Output layer: สร้างผลลัพธ์ เช่น
ประเภทภาพหรือค่าที่คาดการณ์ - Loss function:
วัดความแตกต่างระหว่างผลลัพธ์กับคำตอบที่ต้องการ - Optimizer: ปรับพารามิเตอร์เพื่อลดค่า
loss

Deep Learning มักต้องใช้ข้อมูลและทรัพยากรคำนวณมากกว่าวิธี ML แบบดั้งเดิม
แต่โมเดลที่ฝึกไว้แล้วสามารถนำมาใช้งานได้โดยไม่ต้องฝึกใหม่ทั้งหมด

## 4. Large Language Models (LLM)

Large Language Model หรือ LLM เป็นโมเดลภาษาขนาดใหญ่ที่ฝึกจากข้อความจำนวนมาก
เพื่อสร้างข้อความ ตอบคำถาม สรุปเนื้อหา อธิบายโค้ด และทำงานด้านภาษา

โมเดลสร้างคำตอบโดยคำนวณความเป็นไปได้ของหน่วยข้อความถัดไปตามบริบท
ไม่ได้หมายความว่าทุกคำตอบถูกต้องเสมอไป จึงควรตรวจสอบข้อเท็จจริง โดยเฉพาะเรื่องสำคัญ

คำศัพท์: - Prompt: คำสั่งหรือข้อความที่ส่งให้โมเดล - Context window:
ปริมาณข้อความที่โมเดลรับไว้พิจารณาในหนึ่งครั้ง - Token:
หน่วยย่อยของข้อความที่โมเดลประมวลผล - Hallucination:
กรณีที่โมเดลสร้างคำตอบที่ฟังดูน่าเชื่อถือแต่ไม่ถูกต้องหรือไม่มีหลักฐานรองรับ - Local LLM:
โมเดลภาษาที่รันบนเครื่องของผู้ใช้เอง

## 5. RAG (Retrieval-Augmented Generation)

RAG เป็นวิธีเชื่อม LLM กับฐานความรู้ภายนอก เช่น เอกสารเรียน คู่มือ และไฟล์โค้ด
โดยค้นหาข้อความที่เกี่ยวข้องก่อนส่งให้โมเดลใช้ประกอบคำตอบ

ขั้นตอนทั่วไป: 1. อ่านไฟล์ เช่น PDF, TXT, Markdown หรือไฟล์โค้ด 2.
แบ่งข้อความเป็นส่วนย่อย (chunks) 3. สร้าง embedding ของแต่ละส่วน 4.
เก็บเวกเตอร์และข้อมูลต้นทางไว้ในฐานข้อมูล 5. เมื่อผู้ใช้ถามคำถาม ให้สร้าง embedding
ของคำถาม 6. ค้นหาส่วนข้อความที่คล้ายกับคำถาม 7. ส่งคำถามและข้อความที่ค้นพบให้ LLM 8.
สร้างคำตอบและระบุแหล่งที่มาเมื่อทำได้

ข้อดี: - เพิ่มความรู้จากเอกสารได้โดยไม่ต้องฝึกโมเดลใหม่ - ใช้เอกสารส่วนตัวในเครื่องได้ -
อัปเดตฐานความรู้ได้ด้วยการเพิ่มหรือเปลี่ยนเอกสาร

ข้อจำกัด: - ถ้าเอกสารไม่มีคำตอบ ระบบอาจค้นไม่พบ - ถ้าแบ่งข้อความไม่เหมาะสม
อาจตัดบริบทสำคัญ - ข้อความที่ค้นพบอาจเกี่ยวข้องไม่ตรงทั้งหมด - RAG
ไม่รับประกันว่าคำตอบถูกต้อง ต้องตรวจสอบคำตอบและแหล่งอ้างอิง

## 6. Embeddings และ Vector Search

Embedding คือการแปลงข้อความหรือข้อมูลให้เป็นเวกเตอร์ตัวเลข
เพื่อให้คอมพิวเตอร์เปรียบเทียบความคล้ายกันได้

Vector Search ใช้ค้นหาเวกเตอร์ที่ใกล้เคียงกับเวกเตอร์คำถาม วิธีที่ใช้บ่อยคือ cosine
similarity ซึ่งเปรียบเทียบทิศทางของเวกเตอร์

ข้อควรระวัง: - เวกเตอร์ของเอกสารและคำถามต้องสร้างด้วยโมเดล embedding
เดียวกันหรือโมเดลที่เข้ากันได้ - ขนาดเวกเตอร์ต้องตรงกัน - เมื่อเปลี่ยนโมเดล embedding
ควรสร้าง embedding ของเอกสารใหม่ -
คะแนนความคล้ายไม่ใช่ความน่าจะเป็นว่าข้อความนั้นถูกต้อง

## 7. Python สำหรับงาน AI

Python เป็นภาษาที่นิยมในงาน AI เพราะอ่านง่ายและมีไลบรารีจำนวนมาก

แนวคิดพื้นฐาน: - Variable: ตัวแปรเก็บค่า - List: รายการข้อมูลหลายค่า -
Dictionary: ข้อมูลแบบ key-value - Condition: การตัดสินใจด้วย if/elif/else -
Loop: การทำซ้ำด้วย for หรือ while - Function: ชุดคำสั่งที่เรียกใช้ซ้ำได้ - Exception
handling: จัดการข้อผิดพลาดด้วย try/except - File I/O: อ่านและเขียนไฟล์

ตัวอย่าง:

``` python
def average(values):
    if not values:
        return 0
    return sum(values) / len(values)

temperatures = [30.5, 31.0, 29.8]
print(average(temperatures))
```

โค้ดนี้สร้างฟังก์ชันหาค่าเฉลี่ย และคืนค่า 0 เมื่อไม่มีข้อมูล เพื่อหลีกเลี่ยงการหารด้วยศูนย์

ไลบรารีที่พบบ่อย: - NumPy: คำนวณเชิงตัวเลขและจัดการอาร์เรย์ - pandas:
จัดการข้อมูลตาราง - scikit-learn: อัลกอริทึม Machine Learning - PyTorch:
สร้างและฝึก Neural Networks - pypdf: อ่านข้อความจาก PDF - Gradio:
สร้างหน้าเว็บสำหรับทดลองใช้งานโมเดล - requests: เรียก HTTP API
ในเครื่องหรือเครือข่าย

## 8. SQL และฐานข้อมูล

SQL เป็นภาษาสำหรับจัดการข้อมูลในฐานข้อมูลเชิงสัมพันธ์

คำสั่งพื้นฐาน: - SELECT: อ่านข้อมูล - INSERT: เพิ่มข้อมูล - UPDATE: แก้ไขข้อมูล -
DELETE: ลบข้อมูล - CREATE TABLE: สร้างตาราง - WHERE: กรองข้อมูลตามเงื่อนไข -
ORDER BY: เรียงลำดับข้อมูล - JOIN: เชื่อมข้อมูลจากหลายตาราง

ตัวอย่าง:

``` sql
SELECT name, score
FROM students
WHERE score >= 80
ORDER BY score DESC;
```

คำสั่งนี้เลือกชื่อและคะแนนของนักเรียนที่ได้คะแนนอย่างน้อย 80 แล้วเรียงคะแนนจากมากไปน้อย

## 9. JavaScript และ Web Dashboard

JavaScript เป็นภาษาที่ใช้เพิ่มการโต้ตอบบนเว็บไซต์ และสามารถใช้พัฒนาฝั่งเซิร์ฟเวอร์ผ่าน
runtime เช่น Node.js ได้

องค์ประกอบที่พบบ่อยใน Web Dashboard: - HTML: โครงสร้างหน้าเว็บ - CSS:
รูปแบบและการจัดวาง - JavaScript: การโต้ตอบและอัปเดตข้อมูล - API:
ช่องทางให้โปรแกรมแลกเปลี่ยนข้อมูล - Chart: แสดงข้อมูลเป็นกราฟ - Authentication:
ตรวจสอบตัวตนผู้ใช้ - Authorization: กำหนดสิทธิ์การเข้าถึง

Dashboard สำหรับระบบ Automation อาจแสดงอุณหภูมิ ความเร็วรอบ กระแสไฟฟ้า
สถานะเครื่องจักร และสัญญาณเตือน

## 10. Automation และ IoT

Automation คือการใช้ระบบควบคุม ซอฟต์แวร์ และอุปกรณ์เพื่อทำงานโดยอัตโนมัติ โดยอาจมี
PLC, ไมโครคอนโทรลเลอร์, เซนเซอร์, มอเตอร์ และ HMI หรือ Dashboard

IoT (Internet of Things)
คือการเชื่อมอุปกรณ์ที่มีเซนเซอร์หรือความสามารถประมวลผลเข้ากับระบบสื่อสาร
เพื่อส่งและรับข้อมูล

องค์ประกอบตัวอย่าง: - Sensor: วัดค่าจากสภาพแวดล้อมหรือเครื่องจักร - Controller:
ประมวลผลและควบคุมอุปกรณ์ - Actuator:
อุปกรณ์ที่ทำให้เกิดการเคลื่อนไหวหรือการเปลี่ยนแปลง - MQTT: โปรโตคอลส่งข้อความแบบ
publish/subscribe - Database: เก็บค่าที่วัดได้ - Dashboard: แสดงสถานะและกราฟ -
Alarm/Interlock: แจ้งเตือนหรือป้องกันการทำงานที่ไม่ปลอดภัย

ระบบความปลอดภัยของเครื่องจักรควรออกแบบแยกจากระบบ AI ทำนายความผิดปกติ
และต้องมีการทดสอบตามข้อกำหนดที่เกี่ยวข้อง

## 11. ตัวอย่างการใช้ AI กับการบำรุงรักษาเครื่องจักร

ข้อมูลที่ใช้ได้อาจประกอบด้วย: - อุณหภูมิ - กระแสไฟฟ้า - ความเร็วรอบ (RPM) -
การสั่นสะเทือน - แรงดันไฟฟ้า - เวลาและสถานะการทำงาน

แนวทางสร้างระบบ: 1. เก็บข้อมูลเซนเซอร์พร้อมเวลา 2.
ตรวจสอบข้อมูลผิดพลาดและค่าที่หายไป 3. สร้างคุณลักษณะ เช่น
ค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐาน 4. เริ่มจากกฎพื้นฐานหรือโมเดล ML ที่เข้าใจง่าย 5.
แบ่งข้อมูลฝึกและทดสอบตามเวลาอย่างเหมาะสม 6. ประเมิน false alarms
และกรณีที่ระบบตรวจไม่พบความผิดปกติ 7.
ให้ผู้เชี่ยวชาญตรวจสอบก่อนนำผลไปใช้ตัดสินใจด้านความปลอดภัย

AI เป็นเครื่องมือช่วยวิเคราะห์
ไม่ควรใช้แทนระบบป้องกันอันตรายที่ออกแบบและทดสอบตามมาตรฐาน

## 12. การทำงานแบบออฟไลน์ด้วย Ollama

Ollama เป็นเครื่องมือสำหรับเรียกใช้โมเดลภาษาบนเครื่องของผู้ใช้ได้ โมเดล Qwen3:4B
สามารถใช้ตอบคำถามทั่วไป ส่วน BGE-M3 สามารถใช้สร้าง embedding สำหรับค้นเอกสารได้

การทำงานออฟไลน์ต้อง: - ดาวน์โหลดโมเดลและไลบรารีไว้ก่อน - ใช้ endpoint ของ
Ollama ในเครื่อง เช่น `http://127.0.0.1:11434` - ไม่เรียกบริการ API
ภายนอกในโค้ด - เก็บเอกสารและฐานข้อมูลไว้ในเครื่อง -
ทดสอบการทำงานโดยปิดอินเทอร์เน็ตหลังติดตั้งเสร็จ
