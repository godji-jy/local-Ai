# Local AI

ผู้ช่วย AI ส่วนตัวที่รันในเครื่องของคุณเอง ใช้ [Ollama](https://ollama.com) เป็นตัวรันโมเดล และ [Gradio](https://gradio.app) เป็นหน้าเว็บ ข้อมูลที่คุยและไฟล์ที่แนบไม่ถูกส่งไปที่ไหน (ยกเว้นตอนเปิดโหมดค้นหาเว็บ ซึ่งจะส่งคำค้นไปยัง DuckDuckGo/Wikipedia)

## ความสามารถ

- 💬 แชตภาษาไทย / อังกฤษ / อัตโนมัติ ตอบแบบสตรีมทีละข้อความ
- 📎 **แนบไฟล์ / วางด้วย Ctrl+V** แล้วถามเกี่ยวกับเนื้อหาในไฟล์ (txt, md, pdf, docx, csv, json และไฟล์โค้ด)
- 🖼️ **วางรูปที่คัดลอกไว้ (Ctrl+V)** หรือแนบรูป แล้วให้ AI ดูและตอบ (ต้องใช้โมเดลที่อ่านรูปได้)
- 📚 **ฐานความรู้ในเครื่อง** ใส่ไฟล์ลงโฟลเดอร์ `knowledge` แล้วให้ AI ค้นและอ้างอิงตอนตอบ (RAG)
- 🔎 **ค้นหาเว็บ** เปิดอ่านหน้าเว็บจริง เลือกเฉพาะส่วนที่ตรงคำถาม พร้อมแหล่งอ้างอิงท้ายคำตอบ
- 🧠 **โหมดคิดลึก** ให้โมเดลคิดก่อนตอบ ช้าลงแต่เหมาะกับโจทย์ยาก

## สิ่งที่ต้องมี

- Python 3.10 ขึ้นไป
- [Ollama](https://ollama.com/download) ติดตั้งและเปิดอยู่
- โมเดลใน Ollama 2 ตัว:

```bash
ollama pull qwen3.5:4b     # โมเดลตอบคำถาม (เปลี่ยนได้ที่ MODEL ใน app.py)
ollama pull bge-m3         # โมเดลสร้าง embedding สำหรับฐานความรู้ / ค้นเว็บ / ไฟล์ยาว
```

## ติดตั้ง

```bash
# สร้างและเปิด virtual environment (Windows)
python -m venv .venv
.venv\Scripts\activate

# ติดตั้งแพ็กเกจ
pip install -r requirements.txt
```

ถ้าอยากให้เปิดเป็นหน้าต่างโปรแกรมแทนเบราว์เซอร์ (ไม่บังคับ):

```bash
pip install pywebview
```

## วิธีรัน

```bash
python app.py
```

- ถ้าติดตั้ง `pywebview` จะเปิดเป็นหน้าต่างโปรแกรม
- ถ้าไม่ได้ติดตั้ง ให้เปิดเบราว์เซอร์ไปที่ http://127.0.0.1:7860

## วิธีใช้งาน

### แชตทั่วไป
พิมพ์คำถามในช่องข้อความแล้วกดส่ง หรือกดการ์ดหัวข้อยอดนิยมตอนเริ่มต้น

### ตั้งค่า (เมนู ⚙️ ด้านล่าง)

| ตัวเลือก | ทำอะไร |
|---|---|
| ภาษา | เลือกให้ตอบเป็นไทย อังกฤษ หรืออัตโนมัติตามคำถาม |
| 🔎 ค้นหาเว็บ | ค้นเว็บและอ่านหน้าเว็บก่อนตอบ (ต้องต่ออินเทอร์เน็ต) |
| 📚 ใช้ฐานความรู้ในเครื่อง | ค้นจากไฟล์ในโฟลเดอร์ `knowledge` |
| 🧠 คิดลึก | ให้โมเดลคิดก่อนตอบ ช้ากว่าแต่แม่นขึ้นในโจทย์ยาก |

> ค่าเริ่มต้นของสวิตช์ค้นหาเว็บและฐานความรู้คือ **ปิด** ต้องเปิดเองก่อนใช้

### แนบไฟล์และรูปในแชต
1. **กดปุ่มแนบ** ในช่องพิมพ์ หรือ **คัดลอกรูป/ไฟล์ไว้แล้วกด Ctrl+V** ในช่องพิมพ์ (เช่น แคปหน้าจอแล้ววางได้เลย)
2. แนบพร้อมกันได้ไฟล์เอกสารสูงสุด 5 ไฟล์ (ไฟล์ละไม่เกิน 20 MB) และรูปสูงสุด 4 รูป
3. ชื่อสิ่งที่แนบจะแสดงเหนือช่องพิมพ์ และอยู่ตลอดการคุย ถามต่อได้หลายคำถาม
4. กด **✖ ล้างไฟล์/รูป** เมื่อไม่ต้องการแล้ว
5. แนบแล้วกดส่งโดยไม่พิมพ์อะไร AI จะสรุปหรืออธิบายสิ่งที่แนบให้

**ไฟล์เอกสาร:** ไฟล์สั้น (รวมไม่เกิน 20,000 ตัวอักษร) ส่งให้ AI ทั้งไฟล์ ส่วนไฟล์ยาวระบบจะเลือกเฉพาะส่วนที่ตรงกับคำถามมากที่สุด ถ้าถามภาพรวมทั้งไฟล์ AI อาจเห็นไม่ครบ

**รูปภาพ:** ต้องใช้โมเดลที่อ่านรูปได้ ระบบจะตรวจให้เองว่า `MODEL` อ่านรูปได้หรือไม่ ถ้าไม่ได้ ให้ติดตั้งโมเดลอ่านรูปแล้วใส่ชื่อใน `VISION_MODEL` ตัวอย่าง:

```bash
ollama pull qwen2.5vl:7b
```

```python
VISION_MODEL = "qwen2.5vl:7b"   # ใน app.py
```

รูปจะถูกย่อให้ด้านยาวไม่เกิน 1280 พิกเซลก่อนส่ง และถูกส่งใหม่ทุกคำถามจนกว่าจะล้าง ถ้าไม่ต้องการแล้วให้กดล้างเพื่อให้ตอบเร็วขึ้น

### ฐานความรู้ในเครื่อง (RAG)
1. ใส่ไฟล์ `.txt` `.md` `.pdf` ลงโฟลเดอร์ `knowledge` (ใส่โฟลเดอร์ย่อยได้)
2. สร้างดัชนี:

```bash
python add_knowledge.py            # เพิ่ม/อัปเดตเฉพาะไฟล์ที่เปลี่ยน
python add_knowledge.py --rebuild  # ลบแล้วสร้างใหม่ทั้งหมด
```

3. เปิดสวิตช์ "📚 ใช้ฐานความรู้ในเครื่อง" ในเมนูตั้งค่า

สคริปต์จะข้ามไฟล์ที่ไม่เปลี่ยน และลบข้อมูลของไฟล์ที่ถูกลบออกจากโฟลเดอร์ให้อัตโนมัติ ถ้าแก้วิธีแบ่งข้อความหรือเปลี่ยนโมเดล embedding ให้รันด้วย `--rebuild`

## โครงสร้างโปรเจกต์

```
.
├── app.py              # ตัวแอปหลัก (หน้าเว็บ + ระบบ AI)
├── add_knowledge.py    # สร้าง/อัปเดตฐานความรู้ใน ChromaDB
├── speed_test.py       # ทดสอบความเร็วโมเดลและ embedding
├── requirements.txt    # รายการแพ็กเกจ
├── knowledge/          # ไฟล์ความรู้ของคุณ (สร้างเอง)
├── chroma_db/          # ฐานข้อมูลเวกเตอร์ (สร้างโดย add_knowledge.py)
└── .venv/              # virtual environment
```

## ปรับแต่ง (ค่าอยู่ด้านบนของ `app.py`)

| ค่า | ความหมาย |
|---|---|
| `MODEL` | โมเดลที่ใช้ตอบคำถาม |
| `NUM_CTX` | ที่ว่างรวมของ prompt + ประวัติ + ข้อมูลอ้างอิง + คำตอบ ยิ่งมากยิ่งกิน RAM/VRAM |
| `MAX_TOKENS_FAST` / `MAX_TOKENS_THINK` | ความยาวคำตอบสูงสุด (โหมดปกติ / คิดลึก) |
| `HISTORY_MESSAGES` / `HISTORY_CHARS` | จำนวนข้อความและความยาวประวัติแชตที่ AI จำ |
| `FETCH_PAGES`, `WEB_TOP_PASSAGES` | จำนวนหน้าเว็บที่เปิดอ่าน / จำนวนชิ้นข้อมูลที่ส่งให้ AI |
| `KB_TOP`, `KB_MAX_DISTANCE` | จำนวนชิ้นจากฐานความรู้ / ความเข้มงวดในการเลือก (ยิ่งต่ำยิ่งเข้มงวด) |
| `FILE_FULL_CHARS`, `FILE_TOP_CHUNKS` | เกณฑ์ส่งทั้งไฟล์ / จำนวนชิ้นเมื่อไฟล์ยาว |
| `VISION_MODEL`, `MAX_IMAGES`, `IMAGE_MAX_SIDE` | โมเดลสำรองอ่านรูป / จำนวนรูปสูงสุด / ขนาดรูปสูงสุดที่ส่ง |

> `NUM_CTX` ต้องเป็นค่าเดียวกันทุกการเรียก และตรงกับ `speed_test.py` ถ้าค่าเปลี่ยนไปมา Ollama จะโหลดโมเดลใหม่ทุกครั้งและช้าลงมาก

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| "เชื่อมต่อ Ollama ไม่ได้" | เปิดโปรแกรม Ollama ให้ทำงานอยู่ (ที่อยู่เริ่มต้นคือ `127.0.0.1:11434`) |
| "Ollama ตอบกลับด้วยข้อผิดพลาด" | ตรวจว่า `ollama pull` ทั้ง 2 โมเดลแล้ว และชื่อตรงกับ `MODEL` / `EMBED_MODEL` |
| เส้นหยักเหลืองใต้ชื่อแพ็กเกจใน VS Code | ยังไม่ได้ติดตั้งแพ็กเกจ หรือ VS Code ใช้ Python คนละตัว: `pip install -r requirements.txt` แล้วกด `Ctrl+Shift+P` → **Python: Select Interpreter** → เลือกตัวที่อยู่ใน `.venv` |
| ช้ามาก / เครื่องค้าง | ลด `NUM_CTX` เป็น 16384 หรือ 8192 (แก้ทั้ง `app.py` และ `speed_test.py`) และปิดโหมดคิดลึก |
| ค้นเว็บแล้วได้ข้อมูลสั้นๆ | ยังไม่ได้ติดตั้ง `trafilatura` (อ่านหน้าเว็บ) หรือ `ddgs` (ค้นหา): `pip install trafilatura ddgs` |
| ฐานความรู้ไม่เจอข้อมูลที่ควรเจอ | รัน `python add_knowledge.py --rebuild` และลองเพิ่ม `KB_MAX_DISTANCE` เช่น 0.65 |
| แนบ PDF แล้วอ่านไม่ได้ | น่าจะเป็น PDF ภาพสแกน ต้องทำ OCR ก่อน |
| แนบ .docx ไม่ได้ | `pip install python-docx` |
| วางรูปแล้วขึ้นว่าอ่านรูปไม่ได้ | `MODEL` ไม่รองรับรูป ติดตั้งโมเดลอ่านรูปแล้วตั้ง `VISION_MODEL` |
| กด Ctrl+V แล้วไม่มีอะไรเกิดขึ้น | คลิกในช่องพิมพ์ก่อนแล้วค่อยวาง และต้องเป็นรูปหรือไฟล์ที่คัดลอกไว้ (วางข้อความธรรมดาจะกลายเป็นข้อความ) |
| คำตอบถูกตัดกลางทาง | เพิ่ม `MAX_TOKENS_FAST` (และ `NUM_CTX` ตามความจำเป็น) หรือพิมพ์ "ต่อ" |

## ทดสอบความเร็ว

```bash
python speed_test.py
```

จะแสดงเวลาตอบของโมเดล (ครั้งแรกรวมเวลาโหลดโมเดล) ทั้งโหมดปกติ โหมดคิดลึก และการสร้าง embedding

## ข้อควรรู้

- โมเดลขนาดเล็กอาจตอบผิดหรือแต่งข้อมูลได้ ควรตรวจสอบข้อมูลสำคัญจากแหล่งอ้างอิงที่ระบบแสดงท้ายคำตอบ
- เนื้อหาจากเว็บและไฟล์เป็น "ข้อมูล" เท่านั้น ระบบสั่งให้โมเดลไม่ทำตามคำสั่งที่ซ่อนอยู่ในนั้น แต่ไม่ได้รับประกันได้ทั้งหมด
